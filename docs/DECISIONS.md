## DEC-003：第一阶段采用最小 Single-Agent baseline

- 状态：`ACCEPTED`
- 日期：2026-09-13
- 决策：第一阶段优先建立 Single-Agent、少量工具和 benchmark baseline；在得到实验数据前不引入复杂 Multi-Agent 架构。
- 理由：先获得可比较的基线数据，再判断增加协作 Agent 的收益和成本。

## DEC-004：推理与物理真实性分工

- 状态：`ACCEPTED`
- 日期：2026-09-13
- 决策：LLM 负责推理和决策，仿真器与验证器负责物理与数值真实性。
- 理由：模型输出不能替代可复现的计算、仿真和验证证据。

## DEC-005：Codex 与 Qwen 采用共享事实源和提交式交接

- 状态：`ACCEPTED`
- 日期：2026-09-13
- 决策：在用户最终授权和 GPT/ChatGPT 规划、审查下，Codex 主要承担软件工程执行，Qwen 主要承担本地科研执行。双方共享同一套仓库事实源，在同一工作树中顺序写入，并以干净 Git commit 和验证证据交接。
- 边界：这是人工治理的双模型协作规则，不代表已经实现运行时 Multi-Agent、Qwen 模型接入、共享工具层或统一结果 Schema。
