# 研究计划

## 总体目标

建立一个面向光子芯片设计的 AI Agent Harness 研究平台，以可复现实验比较模型、Agent 架构、工具调用方式和结构化设计表示的能力与局限。

## 研究问题

- 不同 LLM 在需求理解、设计推理、工具选择、错误恢复和结果解释方面有何差异？
- 本地 Qwen 模型与 GPT 等模型在质量、成本、延迟和可部署性方面如何权衡？
- 少量受控工具能否提高 Single-Agent 的可验证任务成功率？
- DesignSpec 等结构化表示能否减少歧义并提高工具调用可靠性？
- Multi-Agent 在哪些任务上带来可测量收益，其协调成本是多少？
- 如何用仿真器、验证器和实验记录约束 LLM 结论的物理真实性？

## 分阶段路线

### 阶段 1：可测量的最小基线

定义一个边界清晰的小型光子设计任务集、评价指标和可复现运行协议，建立 Single-Agent 与少量工具的 baseline。

### 阶段 2：模型与表示比较

在相同任务、工具和评价协议下比较 Qwen 本地模型与 GPT 等模型，并研究结构化设计表示的影响。

### 阶段 3：工具链与验证闭环

按实验需求接入设计、仿真、优化和验证工具，建立从 Agent 决策到物理验证的可追溯闭环。

### 阶段 4：架构比较

在 Single-Agent 基线充分后，设计有限的 Multi-Agent 对照实验，评价成功率、成本、延迟、稳定性和可解释性。

### 阶段 5：场景扩展

根据前述证据评估 DAS 光电混合集成设计作为验证场景，并评估 Photonic AI Computing 作为扩展方向。

## 当前限制

本计划描述研究顺序，不授权提前实现各阶段。每一阶段都必须先在 `docs/TASK.md` 中形成唯一、边界明确、可验收的任务。
