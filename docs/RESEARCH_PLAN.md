# 研究计划

## 总体目标

建立一个面向光子芯片设计的 AI Agent Harness 研究平台，以可复现实验比较模型、Agent 架构、工具调用方式和结构化设计表示的能力与局限。

## 当前阶段：Phase 1

当前仍处于国内外研究现状、发展前景、核心难点和技术路线调研阶段。本阶段只形成候选理论框架、Research Questions、证据地图和待验证假设，不开发 Agent、不接入模型，也不实现 Harness。

### Capability Boundary Research

Agentic PIC Design 调研新增一条独立主线：`Model Internalization vs Harness Externalization`。重点调查：

- Knowledge Boundary；
- Task Boundary；
- Adaptive Tool Calling；
- Uncertainty；
- Tool Cost；
- Verification；
- Benchmark。

该主线研究模型内部推理与外部 Harness 能力如何合理分工，但不预设“更多能力交给模型”或“更多能力工具化”必然更优。

## 研究问题

- 不同 LLM 在需求理解、设计推理、工具选择、错误恢复和结果解释方面有何差异？
- 本地 Qwen 模型与 GPT 等模型在质量、成本、延迟和可部署性方面如何权衡？
- 少量受控工具能否提高 Single-Agent 的可验证任务成功率？
- DesignSpec 等结构化表示能否减少歧义并提高工具调用可靠性？
- Multi-Agent 在哪些任务上带来可测量收益，其协调成本是多少？
- 如何用仿真器、验证器和实验记录约束 LLM 结论的物理真实性？

## 分阶段路线

### 阶段 1：研究现状与技术路线调研

调研国内外研究现状、发展前景、核心难点和候选技术路线，形成证据充分的研究问题、评价维度和实验假设，不进行工程实现。

### 阶段 2：可测量的最小基线

定义一个边界清晰的小型光子设计任务集、评价指标和可复现运行协议，建立 Single-Agent 与少量工具的 baseline。

### 阶段 3：模型与表示比较

在相同任务、工具和评价协议下比较 Qwen 本地模型与 GPT 等模型，并研究结构化设计表示的影响。

### 阶段 4：工具链与验证闭环

按实验需求接入设计、仿真、优化和验证工具，建立从 Agent 决策到物理验证的可追溯闭环。

### 阶段 5：架构比较

在 Single-Agent 基线充分后，设计有限的 Multi-Agent 对照实验，评价成功率、成本、延迟、稳定性和可解释性。

### 阶段 6：场景扩展

根据前述证据评估“DAS 光电混合集成 × 面向智能体的 PIC 设计”作为交叉验证场景，目标是研究人工智能能否完成 DAS 系统需求到芯片设计、工具验证和失败修正的可追溯闭环；光子人工智能计算作为潜在扩展方向。

## 当前限制

本计划描述研究顺序，不授权提前实现各阶段。每一阶段都必须先在 `docs/TASK.md` 中形成唯一、边界明确、可验收的任务。
