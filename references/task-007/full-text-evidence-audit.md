## 影响路线选择的对抗性结论

1. **“Agentic PIC 已形成全流程自动设计”——不成立。** strongest counterexample 是：最强对象仍分别卡在结构有效性、专家初始化、紧凑模型评价、脚本生成或缺少公开实现；没有单一公开系统达到通用、开源、全波/电路/版图验证、失败恢复和 foundry signoff。
2. **“PIC 集成自然提高 DAS 核心性能”——不成立。** 1007 km 非 PIC DAS 是距离指标的直接反例；集成更直接改善尺寸、重量、功耗、耦合和工程一致性，但是否改善灵敏度/距离取决于完整链路。
3. **“光子核心高 TOPS/W 代表完整 AI 系统更优”——不成立。** 公开论文的激光、转换、控制、温控、存储和数据移动边界不统一，任务和精度也不同。
4. **“typed IR / MCP / 多 Agent 本身构成创新”——不成立。** 这些首先是工程机制；只有对可靠性、可追溯性或科学任务表现产生可测量净收益时，才可能支持独立研究结论。
