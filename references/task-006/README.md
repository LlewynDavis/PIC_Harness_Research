## 证据边界

- `FACT（事实）`：可由论文正文、官方页面或已验收仓库材料直接支持。
- `AUTHOR CLAIM（作者报告）`：作者报告但本项目没有复算或复现实验。
- `CODE VERIFIED（源码核验）`：固定提交中的代码结构可见，不代表本机运行或物理正确。
- `INFERENCE（推论）`：基于多项证据的本项目判断。
- `UNKNOWN（未知）`：当前证据不足。
