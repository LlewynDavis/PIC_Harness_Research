# 第一章｜研究问题与调研范围

状态：`ASSISTANT DISCUSSION DRAFT / USER REVIEW PENDING`，2026-10-14。以下是辅助讨论稿，不是研究者已经确认的理解或正式定稿。

## 1.1 从器件设计流程引出问题

项目的长期目标是建立面向光子芯片设计的 Agent Harness，使 Agent 能够组织设计、仿真与优化工具。当前调研从较简单的器件任务出发，分析已有路径及具体决策问题。

光子器件设计不仅是生成一个几何结构，还需要建立材料与仿真模型、计算性能、检查约束，并根据结果修改设计。已有研究将 Agent 引入这一过程，使其能够组织工具调用并开展设计迭代。[1,2]

以降低波导弯曲损耗为例，设计者需要确定器件平台、工作波长、尺寸约束和评价指标，再选择弯曲形状及相关参数。当仿真结果不理想时，下一步不一定是继续修改结构：材料赋值、求解器设置、结果提取或当前搜索策略，都可能需要检查。这个例子用于说明决策问题，不代表本课题已经选定波导弯曲作为唯一研究对象。

本报告关注的核心环节，是 Agent 得到仿真反馈之后，如何判断问题并选择下一步动作。自然语言理解、结构化表达、工具调用和版图验证是流程中的重要部分，但我从课题组资源和时间精力考量出发认为可采取现成有效方案来跑通流程，课题方向聚焦于解决一个工程难点。

## 1.2 本报告所讨论的自主设计

报告区分以下四类工作：
| 工作类型 | 主要完成的事情 | 单凭这一能力不能证明什么 |
|---|---|---|
| 脚本生成 | 将描述转换为代码或工具指令 | 指令已经执行，或结果满足需求 |
| 工具执行 | 调用求解器或设计工具，获得产物与反馈 | 仿真设置、物理模型和结果判断正确 |
| 自主优化 | 根据反馈选择修改、调用工具、评价并继续迭代 | 全局最优、跨器件通用或完全无需专家 |
| 完整芯片设计 | 组织器件、电路、版图及相应验证环节 | 单个器件仿真或 GDS 生成即可代表制造签核 |

我暂将“自主”理解为：在明确的设计目标和约束下，Agent 根据已有结果与工具反馈选择后续动作，而不是每次修改都由人预先指定。目标是让优化过程能够自主推进，并在证据不足或超出能力边界时允许专家介入。可核查的记录服务于这一目标，而不是以生成解释报告代替优化能力。

## 1.3 核心研究问题

本轮调研围绕以下问题展开：

> Agent 如何依据仿真反馈，合理选择修复设置、继续调参或改变策略，使优化更可靠地继续推进？

这一问题可以分为三个相互关联的判断：反馈是否足以支持决策；当前设计是否还有值得继续搜索的方向；改变设置或策略的依据是否成立。

例如，结构尺寸与需求不一致时，可以先通过确定性检查定位偏差；仿真成功但性能未达标时，需要进一步区分模型或数值问题与设计不足；多次尝试未改善时，还需判断是局部搜索停滞，还是当前参数化确实受限。因此，不能只凭“程序运行成功”“性能未达标”或“连续几次没有改善”，直接决定下一步动作。

本报告不预设现有 Agent 完全缺少诊断和策略选择。已有工作已经展示相关行为，后续章节需要比较其适用条件、证据和局限，再讨论是否存在值得改进的环节。[1,2] 也不预设 Agent 必然优于固定规则或数值优化：如果简单方法能够满足问题需求，它应当作为可复用基础和必要的比较对象。

## 1.4 调研范围与材料依据

调研以光子器件设计与仿真优化 Agent 为中心，重点分析 PhIDO、Lumi、HALO 和 AutoPhotonicDesign，并按实际任务区分版图/电路设计、仿真执行、纳米光学设计和器件自主优化。其他项目只在能够解释工具机制或提供重要反例时作为补充，不重新扩充大规模候选池。[3]

DAS 仅作为应用背景，原有 DAS 和光子 AI 计算成果保留在上一份报告中，本次不重新展开。商业求解器和开源工具均可纳入路径比较，代码开放与工具许可作为依赖条件单独说明。长期记忆与跨任务经验复用保留为待研究观点，不作为本轮候选方案的核心模块。

材料主要复用已有调研及本轮定向核读的论文原文、公开代码和官方文档，重点关注 2021–2026 年相关工作；必要的早期物理原理作为背景引用。本报告属于定向技术调研，不宣称完成了穷尽性系统综述。

对于已有研究，区分材料中可核实的内容、作者报告的结果、静态源码观察、研究者分析以及尚未明确的问题。源码存在不等于能够复现，调用求解器不等于物理正确，生成版图不等于可制造。未执行的仿真和实验不作为本项目结果。
