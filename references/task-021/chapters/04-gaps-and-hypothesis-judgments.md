# 第四章｜现有不足与 H1／H2／H3 的判断

2026-10-15 讨论初版

## 4.1 H1：从已有诊断能力转向可靠的行动选择

“现有 PIC Agent 普遍缺少物理诊断与决策”这一判断不成立。AutoPhotonicDesign 的 RF 案例记录了设计家族切换，并将停滞指标与新方案的预期作用写入日志；作者还报告了仿真基础设施问题的修正。[1] 实例表明Agent 已经能够在部分任务中提出原因解释，并据此改变行动。

困难在于判断与行动的可靠性。日志记下了理由，并不直接说明理由正确，也不说明切换方案比继续搜索更合适。同一工作的多物理 MZM 案例中，Agent 识别了部分设置问题，专家建立参考时又补充了其他修正。[1] 诊断能够帮助推进流程，但仍可能遗漏影响结果的条件。

因此应该关注现有诊断证据能否支持合理行动，以及后续结果能否帮助修正判断。原因识别服务于设计推进，不要求在采取每一步行动之前穷尽全部根因。对于证据尚不充分的问题，可以进行有依据、受控且可回退的尝试；关键在于明确行动依据、预期观察和实际结果之间的关系。

这也要求区分不同层次的成功。Lumi 将执行、设置和结果分别评价，说明流程运行完成与所请求设计得到正确评价是不同问题。[2] 设计决策需要同时考虑需求一致性、结果可信度和方案表现，不能只根据程序是否运行或性能数值是否改善来判断。

## 4.2 H2：物理知识应改变决策，而不只是补充解释

物理知识参与 Agent 设计，可以落实为三个作用：1️⃣缩小可能原因的范围 2️⃣筛选值得尝试的动作 3️⃣提出动作之后可核查的预期。
以波导弯曲损耗停滞为例，Agent 除了读取损耗，还需要结合当前结构与材料、求解条件、已有搜索范围，以及必要的场分布或模式信息，判断下一步更值得检查设置、继续搜索，还是改变结构。

这些信息不需要每轮重新获取。基本记录持续保留，已有检查和历史结果可以复用；深入分析在异常、停滞或最佳方案确认时再触发。参考已有设计时，也要比较其工作条件与当前需求的差异，使物理知识转化为可采用的设计依据。

AutoPhotonicDesign 同时使用物理先验、搜索和工程检查；HALO 的配置比较涉及工作流与工具自由度，评价器生成还与模型配置耦合。[1,3] 整体系统得到改善，可能来自这些因素的共同作用，不能只归因于推理解释。

总之初步判断是：物理知识具有帮助 Agent 约束解释和选择行动的潜力，其具体贡献应落到“改变了什么判断、选择了什么动作、结果是否支持预期”。如果解释没有影响动作，或后续观察不支持原判断，就需要重新审视其作用。

## 4.3 H3：Agent 相比规则和优化器增加什么

当模型、目标、约束和搜索空间已经明确时，可以先采用规则检查与优化器组成自动流程。明确的尺寸和材料要求适合逐项核对；给定设计空间内的数值搜索可以交给优化方法。结构搜索也不是 Agent 专属能力，例如已有 HiLAB 方法结合部分拓扑优化、变分自编码器与贝叶斯优化，开展自由形状和物理超参数搜索。[4]

本报告采用以下职责分工：

| 任务 | 简单方案 | Agent 值得关注的增量 |
|---|---|---|
| 明确需求与规则核对 | 字段校验、确定性检查 | 识别需求歧义，提出需要补充的条件 |
| 已知设计空间内的性能搜索 | 参数优化或逆设计 | 选择和配置优化工具，衔接其他设计动作 |
| 已知报错和违规处理 | 固定检查与修复规则 | 综合规则未覆盖或多种问题混合的反馈 |
| 性能停滞与方案调整 | 预设停止条件、多方案搜索 | 结合需求、物理依据和历史，协调检查、优化与方案切换 |

规则可以选择工具和切换策略，如果触发条件和动作能够预先清楚规定，固定流程可能已经足够。Agent 的价值在于面对不同问题组合时综合多种证据，减少逐项编排决策的工作，同时保持行动可靠。

H3 的初步判断是：规则守住明确要求，优化器承担数值搜索，Agent 依据反馈协调检查、修复、优化与方案调整。其增量价值具有适用条件，需要说明哪些决策确实受益于 Agent，哪些直接采用现有自动化已经足够。新建模或计算能力仍由人参与补充和检查，再提供给 Agent 使用。

## 4.4 面向可靠器件与电路设计的具体缺口

综合三个问题，值得进一步研究的是反馈与设计行动之间的连接。现有系统已有日志、重试、保留与回退等机制；当前需要细化的是这些依据如何支撑方案选择，以及在什么条件下值得继续、修复或转向。

具体问题存在于：1️⃣反馈是否足以支持当前动作 2️⃣停滞时应继续还是改变方向 3️⃣局部改善是否满足整体设计要求；这些问题既可能通过工程规则改进，也可能需要 Agent 参与综合判断。例如，配置可比性可以先用版本记录和固定评价条件处理；平台期可以先采用优化器停止条件或预设多方案搜索。只有当这些办法不足以处理具体情境时，才进一步分析 Agent 决策的增量。

当前优先考虑的切入口是：Agent 如何依据仿真与验证反馈，合理选择修复模型或设置、继续优化、改变器件或电路方案，使设计在需求与约束下可靠推进。重点是行动选择及其反馈修正，证据记录用于支持这一过程。第五章将在此基础上整理初步方案、可复用基础、简单替代和主要风险。
