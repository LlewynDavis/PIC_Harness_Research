# 实验记录

`experiments/` 是本项目科研实验事实记录的入口。当前尚未运行任何实验。

后续每项正式实验应使用独立目录，并记录研究问题、假设、模型与工具版本、输入、配置、环境、运行步骤、原始输出位置、评价指标、结果、失败、限制和对应 Git commit。

建议实验目录使用稳定编号与简短名称，例如 `EXP-001_single_agent_baseline/`。目录结构应由首个获准实验的实际需求决定，不在当前阶段提前创建。

大体积原始输出和生成结果默认不提交 Git；如果存放在外部位置，实验记录必须保留可追溯标识、校验信息和获取说明。不得伪造结果，也不得用 LLM 判断替代仿真或验证证据。
